# புண்ணிய நாடு / The Sacred Land

**Tamil title:** புண்ணிய நாடு  
**English title:** The Sacred Land  
**Category:** Poem  
**Source:** <http://www.annavinpadaippugal.info/kavithaigal/punniya_naadu.htm>  
**Publication:** *Dravida Nadu*, Soviet Victory Special Issue

## Source Tamil (verbatim)

புண்ணிய நாடென்று சொலும்இந்த நாட்டில்
புழுப்போல துடிக்கின்றார் ஏழை மக்கள்!
கண்கொண்டு பார்பதற்கே சகிக்கவில்லை!
(திராவிடநாடு - சோவியத் வெற்றி மலர்)

## English Translation

In this country proclaimed a sacred land,  
the poor writhe like worms!  
The very sight is more than the eyes can bear!

## Translator's Notes

The title and opening description are pointedly ironic: proclaimed sanctity is
set against the visible suffering of the poor.
