# எழுச்சி நாள் உரை

Source: <http://www.annavinpadaippugal.info/speech03_ezhuchi.htm>

அறிஞர் அண்ணாவின் சொற்பொழிவுகள்
எழுச்சி நாள் உரை
(சேலம் உருக்காலை மற்றும்
தூத்துக்குடி ஆழ்கடல் திட்டம் சம்மந்தமாக)
